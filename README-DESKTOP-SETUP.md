# دليل تحزيم تطبيق JMApps Stock Monitor إلى برنامج تنصيب (Setup .exe) وأنظمة التشغيل الأخرى

تم تجهيز وتكوين التطبيق بالكامل ليعمل كتطبيق سطح مكتب حقيقي (Native Desktop App) مع دعم كامل لنظام التنصيب (NSIS Setup Wizard) على **Windows**، وحزم التثبيت على **macOS** و **Linux**.

---

## 🚀 كيفية بناء ملف التنصيب `Setup.exe` (Windows Installer)

### الطريقة المباشرة (نقرة واحدة على Windows):
1. قم بفك ضغط ملفات المشروع بعد تصديرها (Export ZIP).
2. انقر نقراً مزدوجاً على الملف: **`build-setup-exe.bat`**.
3. سيقوم الملف تلقائياً بتثبيت التبعيات، بناء المشروع، وتوليد ملف التنصيب داخل مجلد `dist-electron/`.

### الطريقة عبر سطر الأوامر (Terminal / Command Prompt):
```bash
# 1. بناء حزمة التنصيب لنظام ويندوز (.exe Setup + Portable)
npm run build:exe

# أو
npm run package:win
```

النتيجة ستكون في مجلد **`dist-electron/`**:
- **`JMApps Stock Monitor-Setup-1.0.0-x64.exe`**: برنامج تثبيت احترافي (معالج التثبيت، إنشاء اختصار على سطح المكتب وقائمة ابدأ، وإلغاء التثبيت).
- **`JMApps Stock Monitor-1.0.0-portable.exe`**: نسخة محمولة تعمل مباشرة بدون تثبيت.

---

## 🍏 كيفية بناء الحزم لأنظمة التشغيل الأخرى (macOS & Linux)

### 1. نظام ماك (macOS):
```bash
npm run build:mac
```
- ينتج ملف **`.dmg`** لتثبيت التطبيق بالسحب إلى مجلد التطبيقات Applications، بالإضافة إلى ملف **`.zip`**.

### 2. نظام لينكس (Linux):
```bash
npm run build:linux
```
- ينتج ملف **`.AppImage`** القابل للتشغيل المباشر على جميع توزيعات لينكس (Ubuntu, Fedora, Debian, Arch)، وملف **`.deb`** لتوزيعات Debian/Ubuntu.

### 3. بناء جميع الأنظمة دفعة واحدة (All Platforms):
```bash
npm run build:all
```

## ⚙️ مميزات حزمة سطح المكتب (Desktop Features)

1. **خادم محلي مدمج + قاعدة بيانات SQLite**:
   - يعمل التطبيق حتى عند انقطاع الإنترنت للبيانات المحفوظة.
   - يتم تخزين قاعدة البيانات بأمان في مجلد بيانات المستخدم (`%APPDATA%` على ويندوز و `Application Support` على ماك).
2. **معالج التثبيت المخصص (NSIS Setup Wizard)**:
   - إمكانية اختيار مسار التثبيت المخصص (Custom Directory).
   - إنشاء اختصارات سطح المكتب وقائمة ابدأ تلقائياً.
   - دعم التحديثات وإلغاء التثبيت النظيف (Uninstaller).
3. **تحديث ومراقبة الأسعار والتنبيهات المباشرة**:
   - محرك التنبيهات الفوري والإشعارات الصوتية يعمل بكفاءة عالية على نظام التشغيل.
